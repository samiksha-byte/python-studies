# Campus Mood Bot

## Project Description

Campus Mood Bot is a simple chatbot built using Python and Flask.

The chatbot helps students with:
- Exams
- Placements
- Projects
- Python Learning
- Motivation

## Technologies Used

- Python
- Flask
- HTML

## Concepts Used

- Functions
- Dictionaries
- User Input
- Flask Routing

- hello
- exam
- placement
- project
